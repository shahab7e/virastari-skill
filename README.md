# ویراستاری (virastari)

اسکیل Claude برای **ویرایش حرفه‌ای متن فارسی**: رسم‌الخط، نشانه‌گذاری، عدد و تاریخ، ارجاع و ویرایش زبانی، با ذکر قاعده و صفحهٔ مرجع برای هر اصلاح.

## مرجع‌ها

1. **رسم‌الخط:** «دستور خطّ فارسی» (ویراست دوم، ۱۴۰۴)، فرهنگستان زبان و ادب فارسی
2. **نشانه‌گذاری، عدد، ارجاع و ویرایش زبانی:** «راهنمای ویراستاری و درست‌نویسی»، حسن ذوالفقاری

اگر شیوه‌نامهٔ ناشر یا خواستهٔ صریح کاربر باشد، بر هر دو مقدّم است.

## امکانات

- سه سطح ویرایش: فنی، فنی + زبانی (پیش‌فرض)، کامل
- رعایت نوع متن (شعر، داستان، علمی، اداری، متن کهن و ...)
- خروجی: فایل ویراسته + گزارش ایرادها (docx / md / txt؛ ورودی pdf هم پشتیبانی می‌شود)
- اسکریپت‌های کمکی: `scripts/normalize.py` (اصلاح مکانیکی بی‌خطر) و `scripts/scan.py` (یافتن سرنخ ایرادها)

## نصب

پوشهٔ مخزن را با نام `virastari` درون پوشهٔ اسکیل‌ها بگذارید:

```bash
git clone https://github.com/shahab7e/virastari-skill ~/.claude/skills/virastari
```

برای Claude Desktop / claude.ai می‌توانید پوشه را zip کنید و از بخش Skills بارگذاری کنید.

## استفاده

```
/virastari
```

یا فقط بنویسید: «این متن را ویرایش کن» و متن یا فایل را بدهید.

پیش‌نیاز اسکریپت‌ها: Python 3 و (برای docx) `python-docx`.

## ساختار

```
SKILL.md          دستورالعمل اصلی اسکیل
references/       قواعد و جدول‌های مرجع (نشانه‌گذاری، رسم‌الخط، املا، عدد، ارجاع، خطاها، فرهنگواره)
scripts/          normalize.py و scan.py
```

## نکته

محتوای `references/` خلاصه و فیش‌برداری قواعد از منابع بالاست و جایگزین خود کتاب‌ها نیست؛ برای مرجع کامل به کتاب‌ها مراجعه کنید.
